# Aura Personal OS

Crie uma aplicação web moderna de Assistente Pessoal com Inteligência Artificial, projetada para funcionar como uma central pessoal de produtividade, organização e execução.

O objetivo não é criar apenas um chatbot. Quero uma aplicação que pareça um sistema operacional pessoal, onde o usuário possa conversar com uma IA e, ao mesmo tempo, gerenciar tarefas, compromissos, informações importantes, arquivos, lembretes, objetivos e rotina.

CONCEITO DO PRODUTO

A aplicação deve transmitir a sensação de que o usuário possui uma assistente particular sempre disponível.

A assistente deve ser capaz de:

conversar naturalmente com o usuário;

entender contexto;

lembrar informações importantes;

criar e organizar tarefas;

criar lembretes;

acompanhar compromissos;

ajudar na rotina;

organizar projetos;

armazenar notas;

responder perguntas sobre informações previamente salvas;

acompanhar objetivos;

centralizar informações pessoais relevantes;

sugerir ações com base no contexto.

A aplicação deve ter uma interface extremamente moderna, limpa e premium.

Não quero aparência de dashboard corporativo tradicional.

Quero algo mais próximo de uma combinação entre:

ChatGPT

Notion

Linear

Raycast

Apple Intelligence

um assistente pessoal futurista

Tudo com identidade visual própria.

ESTRUTURA PRINCIPAL

1. HOME

Criar uma página inicial extremamente limpa.

No centro da tela:

"Bom dia, João."

Abaixo:

"O que vamos resolver hoje?"

Depois disso, mostrar um campo grande de interação com a assistente.

Placeholder:

"Pergunte, peça ou organize qualquer coisa..."

Exemplos rápidos abaixo:

Organizar meu dia

Criar uma tarefa

Ver meus compromissos

Fazer uma anotação

Planejar minha semana

A Home também deve mostrar um resumo inteligente do dia.

Exemplo:

Hoje

3 tarefas pendentes

2 compromissos

1 lembrete

Próximo compromisso às 14:30

A assistente pode também apresentar uma pequena mensagem contextual:

"Seu dia está relativamente tranquilo. Você tem uma reunião às 14:30 e duas tarefas prioritárias ainda abertas."

2. ASSISTENTE

Criar uma área completa de conversa com IA.

A interface deve permitir conversas naturais como:

"Me lembra de pagar a internet sexta-feira."

"Marca uma tarefa para eu terminar o projeto amanhã."

"O que eu tenho para hoje?"

"Organiza minha semana."

"Quais tarefas estão atrasadas?"

"Anota que o cliente prefere receber contato pelo WhatsApp."

"Cria uma lista do que eu preciso fazer antes da viagem."

A IA deve identificar automaticamente quando a mensagem representa:

tarefa;

lembrete;

evento;

anotação;

informação para memória;

pergunta;

planejamento;

pesquisa.

Antes de executar ações importantes, a aplicação pode mostrar uma confirmação visual elegante.

Exemplo:

Criar lembrete

Pagar internet
Sexta-feira • 10:00

[Cancelar] [Criar lembrete]

3. VISÃO "HOJE"

Criar uma página chamada Hoje.

Ela deve funcionar como um painel pessoal do dia.

Mostrar:

Bom dia

Data atual.

Agenda

Timeline vertical mostrando os compromissos.

Exemplo:

09:00 — Academia
11:00 — Trabalhar no projeto
14:30 — Reunião
18:00 — Faculdade

Tarefas

Separar por:

Prioridade

Hoje

Atrasadas

Concluídas

Permitir marcar tarefas como concluídas diretamente.

6. LEMBRETES

Criar uma área dedicada para lembretes.

Exemplo:

"Me lembra daqui 30 minutos de ligar para o cliente."

"Me lembra amanhã às 9h de enviar o relatório."

"Todo dia 10 me lembra de pagar a internet."

Suportar:

recorrente;

horário específico;

data específica.

7. NOTAS

Criar uma área de notas simples e elegante.

Permitir:

criar notas;

editar;

fixar;

categorizar;

pesquisar.

A IA deve conseguir utilizar essas notas como contexto.

Exemplo:

Usuário salva:

"O cliente Marcos prefere reuniões pela manhã."

Posteriormente pergunta:

"Qual horário o Marcos prefere?"

A assistente deve conseguir responder utilizando a memória salva.

8. MEMÓRIA

Criar uma área chamada Memória.

Ela representa informações que a assistente aprendeu sobre o usuário.

Exemplos:

Preferências

Prefere reuniões pela manhã.

Pessoas

Marcos — cliente do projeto X.

Trabalho

Trabalha no projeto Workflow.

Rotina

Faculdade segunda, quarta e sexta.

O usuário deve conseguir:

visualizar;

editar;

excluir;

adicionar manualmente informações.

A IA nunca deve parecer invasiva.

Informações importantes salvas automaticamente devem possuir indicação de que foram armazenadas.

9. PROJETOS

Criar uma área de projetos.

Exemplos:

Mostrar progresso visual do projeto.

10. INBOX

Criar uma área chamada Inbox.

Tudo que o usuário adicionar rapidamente pode cair inicialmente aqui.

Exemplo:

"comprar cabo USB-C"

Depois o sistema pode transformar isso em tarefa ou organizar automaticamente.

A ideia é permitir captura extremamente rápida de informações.

EXPERIÊNCIA DA IA

A assistente deve ser o elemento central do produto.

A sensação deve ser:

"Não preciso navegar pelo sistema para fazer as coisas. Posso simplesmente pedir."

Exemplo:

Usuário:

"Me organiza amanhã."

Assistente analisa:

agenda;

tarefas;

pendências;

prioridades.

E apresenta:

Sugestão para amanhã

08:00 — Academia
09:30 — Finalizar relatório
11:00 — Responder cliente
14:00 — Reunião
16:00 — Trabalhar no projeto

Depois mostrar:

Adicionar essa programação ao meu dia

PRINCÍPIO PRINCIPAL DO PRODUTO

A interface não deve obrigar o usuário a administrar o sistema.

A inteligência artificial deve administrar o sistema para o usuário.

O usuário apenas:

fala;

pede;

confirma;

executa.

Todo o restante deve acontecer de forma natural.

Crie inicialmente uma versão funcional completa da interface com dados mockados realistas.

Priorize:

qualidade visual;

experiência de uso;

arquitetura dos componentes;

responsividade;

sensação premium;

integração natural da IA com todas as áreas.

Não simplifique a interface para um CRUD genérico.

Quero que o resultado pareça um produto SaaS real, moderno e pronto para evoluir para uma assistente pessoal completa.
